# XoraMarket

Sistema de gestión de inventario y ventas desarrollado por iniciativa propia para digitalizar un negocio familiar que anteriormente manejaba su información en facturas físicas.

## Funcionalidades

- Registro de productos con precio de compra y venta
- Cálculo automático de ganancia por unidad y por cajón
- Control de stock en tiempo real con alertas de nivel mínimo de inventario
- Módulo de facturación con búsqueda de productos
- Reportes mensuales de ganancias

## Tecnologías

- **Backend:** Python, Flask
- **Base de datos:** SQLite
- **Frontend:** HTML, CSS

## Despliegue

Desplegado en la nube mediante Render.
